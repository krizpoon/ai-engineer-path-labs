# AI Engineer Path support

Help with the AI Engineer Path app for iPhone and iPad, and with the labs in this repository.

**Email:** [ai-engineer@twinkle.hk](mailto:ai-engineer@twinkle.hk). Please include your device, iOS version and the chapter you were reading.

**Lab code:** if a lab script fails or a chapter's code looks wrong, you can also [open an issue](https://github.com/krizpoon/ai-engineer-path-labs/issues) on GitHub (needs a free GitHub account).

**Common questions**

- *Do I need an account or an API key to use the app?* No. Chapters, quizzes and the glossary work offline with no sign-in.
- *Where do I run the code?* On a computer, or in a browser with GitHub Codespaces. See the [README](README.md). Scripts that call Claude need your own Anthropic API key, and API usage is charged by Anthropic.
- *How do I reset my progress?* Delete and reinstall the app. Progress is stored only on your device.

See also the [privacy policy](PRIVACY.md).
