# AI Engineer Path labs

Runnable code for **AI Engineer Path**, an iPhone and iPad course on building LLM applications with Python and Claude. Every named code sample in the twelve chapters is here, with sample data and offline smoke tests.

## Open it in a browser

On GitHub, choose **Code → Codespaces → Create codespace on main**. It works from a laptop, iPad or phone browser, and the dev container installs Python 3.12 and the lab requirements. Codespaces bills the account that creates the codespace, which includes a free monthly allowance.

Scripts that call Claude need `ANTHROPIC_API_KEY`. Add it as a Codespaces secret at <https://github.com/settings/codespaces> and allow this repository to use it. The smoke tests need no key.

## Run it locally

See [`labs/README.md`](labs/README.md) for setup, the command for each chapter's exercises, and the smoke tests.

## About this repository

The files under `labs/chNN-*/` are generated from the course chapters, so their headers say to edit the chapter instead. Changes are made in the course and copied here; issues and pull requests are still welcome.
